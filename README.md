# Flower-knight-girl-Viewer_update

[English Version (英文版)](README_EN.md)

Flower knight girl Viewer专用更新程序，放到package.nw目录里（跟scenes目录同级）更新即可。

**更新程序现已集成搜索功能修复，更新完成后会自动生成 meta.js 文件，无需单独运行搜索修复程序。**

如果运行更新程序时遇到错误，请尝试关闭或开启代理。

最新程序请点击tags下载，win7和win10目录中的程序还是旧的。

**程序优先根据diffrentList.txt的ID更新场景，如果不需要，请删除diffrentList.txt再执行更新程序（如果diffrentList.txt过期，会自动爬取wiki生成新的文件）**
